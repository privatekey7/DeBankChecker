Fix: Explicitly set status to ERROR for uncorroborated balances

Currently, if the attempt budget is exhausted without reaching
CORROBORATION_MIN_AGREE, the fallback logic selects the most conservative
snapshot and returns it but leaves its status as "OK". This causes `main.py`
to accept this potentially phantom balance as a valid result.

This commit adds `chosen["status"] = "ERROR"` to the fallback logic so that
uncorroborated balances are correctly flagged as errors and excluded from the
successful totals.
